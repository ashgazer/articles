# Spanish Imperfect Subjunctive

This is the tense that powers hypotheticals — "if I **had** money, I **would** travel" — and polite requests. It's the past/hypothetical counterpart to the present subjunctive you already have, triggered by the same WEIRDO phrases but in a past or unreal frame.

---

## Formation — the "3rd person plural preterite" rule

This is the neat bit: it's built entirely off a form you already know.

1. Take the **ellos** form of the **preterite** (e.g. hablar → *hablaron*, tener → *tuvieron*)
2. Drop the **-ron**
3. Add the endings below

Because it's built from the preterite, **every irregular preterite carries straight in** — no new irregulars to learn.

| Person | hablar (hablaron→) | comer (comieron→) | tener (tuvieron→) |
|---|---|---|---|
| yo | habla**ra** | comie**ra** | tuvie**ra** |
| tú | habla**ras** | comie**ras** | tuvie**ras** |
| él/ella/ud. | habla**ra** | comie**ra** | tuvie**ra** |
| nosotros | hablá**ramos** | comié**ramos** | tuvié**ramos** |
| vosotros | habla**rais** | comie**rais** | tuvie**rais** |
| ellos/uds. | habla**ran** | comie**ran** | tuvie**ran** |

*(The nosotros form takes an accent: hablá**ramos**, tuvié**ramos**.)*

**Note:** there's an alternative **-se** ending set (hablase, hablases…) that means the same thing. It's more formal/literary and common in Spain; the **-ra** set above is more universal. Learn -ra, recognise -se.

## Irregulars carry from the preterite (no new ones)

| Infinitive | ellos preterite | Imperfect subjunctive (yo) | Maps to English |
|---|---|---|---|
| ser / ir | fueron | fuera | if I were / went |
| estar | estuvieron | estuviera | if I were |
| tener | tuvieron | tuviera | if I had |
| hacer | hicieron | hiciera | if I did/made |
| poder | pudieron | pudiera | if I could |
| poner | pusieron | pusiera | if I put |
| decir | dijeron | dijera | if I said |
| venir | vinieron | viniera | if I came |
| haber | hubieron | hubiera | if there were |
| saber | supieron | supiera | if I knew |

*Know your preterite irregulars → you already know these.*

## Main use 1: hypothetical "if" sentences

The classic pattern. **Unreal or unlikely** conditions:

> **Si + [imperfect subjunctive], + [conditional].**

| Spanish | English |
|---|---|
| Si **tuviera** dinero, viajaría. | If I had money, I would travel. |
| Si **fuera** tú, no lo haría. | If I were you, I wouldn't do it. |
| Si **pudiera**, te ayudaría. | If I could, I'd help you. |
| Si **estuviéramos** allí, lo veríamos. | If we were there, we'd see it. |

**Contrast with real conditions** (these use plain present, *not* subjunctive):
- *Si **tengo** tiempo, voy.* — If I have time, I go. (real, likely)
- *Si **tuviera** tiempo, iría.* — If I had time, I'd go. (hypothetical, unlikely)

## Main use 2: past-frame WEIRDO triggers

When the trigger verb is in the **past**, the subjunctive after it shifts to imperfect subjunctive:

| Present frame | Past frame | English |
|---|---|---|
| Quiero que **vengas** | Quería que **vinieras** | I wanted you to come |
| Espero que **esté** bien | Esperaba que **estuviera** bien | I hoped he was okay |
| Es importante que **hables** | Era importante que **hablaras** | It was important that you spoke |
| Dudo que **sea** verdad | Dudaba que **fuera** verdad | I doubted it was true |

**Rule:** past trigger → past (imperfect) subjunctive. Same WEIRDO logic, shifted back in time.

---

## Main use 3: extra-polite requests

Softer and more courteous than the conditional alone:

| Spanish | English |
|---|---|
| **Quisiera** un café, por favor. | I would like a coffee, please. (very polite) |
| Si **fuera** tan amable… | If you would be so kind… |
| **Quisiera** preguntarle algo. | I'd like to ask you something. |

*Quisiera* (from querer) is worth banking as a set phrase — it's the polished way to say "I'd like."

## The whole hypothetical system, in one view

| Type | If-clause | Result-clause | Example |
|---|---|---|---|
| **Real** (likely) | si + present | present/future | Si tengo tiempo, iré |
| **Unreal** (hypothetical) | si + imperfect subj. | conditional | Si tuviera tiempo, iría |
| **Past unreal** (didn't happen) | si + pluperfect subj.* | conditional perfect | Si hubiera tenido tiempo, habría ido |

*\*The third row (si hubiera tenido… → "if I had had…") is the past-hypothetical, built from **hubiera** + past participle. It's the natural final step once this file is solid — you already have all the pieces (imperfect subjunctive of haber + participles from the perfect-tense file).*
