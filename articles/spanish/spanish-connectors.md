# Spanish Connectors & Fillers (sound fluent, not just correct)

These are the words that turn a list of correct sentences into flowing speech. Learning ten of these does more for how fluent you *sound* than another verb tense. Grouped by the job they do.

---

## Adding / sequencing

| Spanish | English | Note |
|---|---|---|
| además | besides / what's more | stronger than "also" |
| también | also / too | |
| y luego | and then | narrative |
| primero… luego… | first… then… | |
| por un lado… por otro lado | on one hand… on the other | |
| en primer lugar | firstly | slightly formal |

## Contrasting

| Spanish | English | Note |
|---|---|---|
| pero | but | the everyday one |

| aunque | although / even though | |
| en cambio | on the other hand / whereas | contrast between two things |

## Cause & effect

| Spanish | English | Note |
|---|---|---|
| porque | because | mid-sentence only |
| ya que / puesto que | since / given that | can start a sentence |
| por eso | that's why / so | very common in speech |
| así que | so / therefore | conversational |
| entonces | so / then | huge in spoken Spanish |
| como | since / as | sentence-start cause: *Como llovía…* |
| por lo tanto | therefore | formal |

## Ten to bank first for the meet-up

If you only drill a handful before speaking, make it these — they're the ones that carry the most conversational weight:

1. **entonces** — so / then
2. **o sea** — I mean
3. **pues** — well
4. **de hecho** — in fact
5. **sin embargo** — however
6. **así que** — so
7. **es que…** — it's just that…
8. **la verdad** — honestly
9. **por eso** — that's why
10. **¿sabes?** — you know?

Sprinkle these in and you stop sounding like a textbook and start sounding like a person thinking out loud in Spanish.
